Interactive notebooks explaining diffusion MRI, built with [marimo](https://marimo.io). The course follows a backbone of modules; each module ends with optional branches for going deeper.

## Modules

| # | Module | Run in your browser |
|---|--------|---------------------|
| 2 | From random walks to signal decay (with branch: restricted diffusion) | [![Open in molab](https://marimo.io/molab-shield.svg)](https://molab.marimo.io/github/ChantalTax/dMRI_forward_approaches/blob/main/modules/02_free_diffusion.py/wasm) |

The "Open in molab" link runs the notebook in your browser (WebAssembly). Nothing needs to be installed.

## Run locally

```bash
pip install marimo numpy matplotlib
marimo run modules/02_free_diffusion.py    # lesson view, code hidden
marimo edit modules/02_free_diffusion.py   # editing view
```
